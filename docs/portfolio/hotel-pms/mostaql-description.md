# HOTEL PMS | نظام ذكي لإدارة الفنادق والحجوزات والغرف

منصة تشغيل فندقية بواجهة عربية فاخرة: لوحة مؤشرات، غرف وحالاتها، حجوزات، نزلاء، وتقارير تشغيل، مع صفحة تعريفية للفندق. النسخة المنشورة عرض تفاعلي ببيانات وهمية يمكن تصفحه دون حساب.

## الوظائف

- لوحة تشغيل تعرض إجمالي الغرف، والمتاح، والمشغول، والصيانة، والحجوزات الجارية، ووصول اليوم ومغادرته، ونسبة الإشغال، مع رسوم لتوزيع الحالات.
- إدارة 40 غرفة تجريبية: النوع، السعة، الصورة، البحث والتصفية، وتغيير حالة الغرفة مع سجل للحالة.
- حجوزات بأسماء وهمية: البحث والتصفية، التفاصيل، وتأكيد الحجز أو إلغاؤه، وتسجيل الوصول والمغادرة عندما تسمح حالة الحجز والغرفة.
- دليل نزلاء وهميين مع البحث.
- تقارير تشغيلية للإشغال وتوزيع الحجوزات وحركة الوصول والمغادرة.
- صفحة فندق Grand Azure Hotel للغرف والمرافق والصور. الحجز العام غير مفعّل، ولا يوجد دفع إلكتروني.

المؤشرات داخل العرض تتحدث عند محاكاة تغيير الحالة أو الحجز. زر «إعادة ضبط العرض» يعيد البيانات الأولى، والتحديث يلغي التعديلات.

## التقنيات

Next.js وReact وTypeScript، بواجهة عربية واتجاه من اليمين لليسار وخط Cairo. البيانات محلية داخل المتصفح، بلا قاعدة بيانات وبلا تسجيل دخول.
